练习：Linux 操作系统

本页为动手练习指南：在 CentOS 终端中认识常用 Linux 命令，并查看 FASTA、FASTQ、基因表达矩阵与样本信息表等常见生物信息学文件，完成简单统计与课堂练习。

一、练习说明

  • 实验名称：Linux 操作系统
  • 实验目的：
    ① 能够登录 CentOS、打开终端并找到桌面文件；
    ② 认识 Linux 常用的目录与文件操作命令；
    ③ 认识 FASTA、FASTQ、表达矩阵和样本信息表；
    ④ 使用简单命令查看文件并统计基本信息；
    ⑤ 能够记录操作结果并作出简要解释。
  • 实验内容和要求：将四个实验文件放到 CentOS 桌面；练习目录切换与文件操作；查看四种生物信息学文件；使用 wc、grep、awk 做简单统计；完成四组课堂练习并整理实验报告。操作环境为机房或个人电脑上的 CentOS 虚拟机（用户名示例：njucm）。
  • 实验中出现的问题汇总：完成实验后，可简要记录操作中遇到的问题及处理方式，例如：找不到文件、路径大小写写错、命令无反应等。建议按「问题现象—检查步骤—如何解决」整理；若未遇到明显问题，也可如实写明。
  • 实验总结：用几句话概括本次收获即可，例如学会了哪些 Linux 命令、四种文件各有什么用途，以及命令行对查看、统计科研数据有什么帮助。结合自己的实际操作来写，不必面面俱到。

本次练习使用以下四个文件（已放在仓库 data/）。可先下载到 Windows，再导入 CentOS 桌面：

三、启动 CentOS 与导入文件

3.1 启动与登录

  1. 打开 VMware Workstation，启动 CentOS 虚拟机。
  2. 使用课程提供的账号登录（示例用户名：njucm），进入图形桌面。
  3. 在桌面空白处或应用程序菜单中找到并打开终端。

3.2 把四个文件放到 CentOS 桌面

  1. 在 Windows 中下载本页「实验数据」中的四个文件（或解压课程发放的数据包）。
  2. 选中 gene_sequences.fasta、example.fastq、gene_expression.tsv、sample_table.tsv。
  3. 拖动四个文件到 CentOS 桌面空白处。
  4. 检查桌面是否出现这四个文件。若拖拽无效，可使用机房提供的共享文件夹等方式导入。

3.3 打开终端，进入桌面

桌面路径通常为 /home/njucm/Desktop（若用户名不同，请把路径中的用户名改成自己的）。在终端输入：

cd /home/njucm/Desktop

按 Enter 执行。之后大部分操作都在该目录下进行。

四、Linux 基础命令

以下命令可在桌面目录中逐条练习。建议边敲边观察终端输出。

pwd — 查看当前所在目录

pwd

ls — 列出当前目录里的文件与文件夹

ls

cd — 切换目录。cd .. 返回上一级；再执行绝对路径可回到桌面。

cd ..
cd /home/njucm/Desktop

mkdir — 新建用于练习的文件夹

mkdir practice

touch — 新建空白文本文件

touch test.txt

cp — 复制文件，并保留原来的文件

cp gene_sequences.fasta practice/

mv — 移动文件，也可以修改文件名

mv test.txt practice/result.txt

cat — 显示短文本文件的全部内容

cat sample_table.tsv

head — 查看文件开头的若干行

head -n 5 gene_sequences.fasta

补充：进入 practice 文件夹后可用 ls practice 查看其中有哪些文件。

五、认识四种生物信息学文件

5.1 FASTA：gene_sequences.fasta

  • 每条序列的标题行以 > 开头。
  • 标题行之后是 DNA 碱基序列。
  • 本示例文件共有 10 条序列。

查看示例：

head -n 5 gene_sequences.fasta

统计序列条数（统计以 > 开头的标题行）：

grep -c '^>' gene_sequences.fasta

5.2 FASTQ：example.fastq

每 4 行是一条 read：

  1. 第 1 行：read 名称（常以 @ 开头）
  2. 第 2 行：碱基序列
  3. 第 3 行：+ 分隔行
  4. 第 4 行：质量字符

本示例文件包含 10 条 reads。FASTQ 比 FASTA 多了质量信息。

5.3 基因表达矩阵：gene_expression.tsv

  • 第一行：20 个样本编号 S01 至 S20。
  • 第一列：100 个基因 Gene001 至 Gene100。
  • 其余位置：每个基因在各样本中的示例表达值。
head -n 5 gene_expression.tsv

5.4 样本信息表：sample_table.tsv

  • Sample：样本编号 S01 至 S20
  • Group：Control 或 Disease
  • Age：年龄
  • Sex：性别（Female / Male）
head sample_table.tsv

表达矩阵的样本列与样本表的样本行，通常通过 S01–S20 编号对应。若某个编号写错，后续分组或合并分析可能对不上。

六、进阶命令

wc — 统计文本文件行数（例如查看 FASTQ 总行数）

wc -l example.fastq

grep — 搜索包含指定文字的行（例如查找 Gene050）

grep "Gene050" gene_expression.tsv

awk — 统计基因数（表达矩阵第一行是表头，数据行数减 1）

awk 'END {print NR-1}' gene_expression.tsv

awk — 统计 Disease 组样本数量（第二列为 Group）

awk -F '\t' 'NR>1 && $2=="Disease" {n++} END {print n+0}' sample_table.tsv
