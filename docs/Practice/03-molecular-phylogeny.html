Practice/03 分子进化树的构建

分子进化树的构建（MEGA 12）

本练习全程使用 MEGA 12：安装软件 → 导入多物种细胞色素 b（Cyt b）蛋白序列 → 比对 → 建树 → 导出结果。不涉及 R 或其他建树工具。

一、MEGA 12 简介与官网

1.1 软件简介

MEGA 12（Molecular Evolutionary Genetics Analysis）是常用的分子进化与系统发育分析软件，提供序列比对、氨基酸/核酸替换模型、邻接法（NJ）、最大似然法（ML）、最小进化法（ME）等多种建树途径，以及树形编辑与 Bootstrap 检验等图形化功能。课堂以 Windows 安装包为主；其他系统可在官网选择对应版本。

下载与安装前请准备可联网的浏览器；安装过程可能需要本机管理员权限。使用软件须遵守官网公示的许可条款，并限于教学与科研等允许用途。

1.2 官方网站

请认准官方入口，避免从不明第三方站点获取安装包。

官方主页
  • https://www.megasoftware.net/
建议记录
安装完成后记下 MEGA 12 的完整版本号与安装路径，便于对照讲义中的菜单名称。

二、下载与安装

以下以在 Windows 上从官网获取 .exe 安装包为例；若官网选项与下文略有出入，以当前页面为准。

视频教程：MEGA 下载与安装（MP4）

2.1 打开主页并进入下载流程

  • 打开 https://www.megasoftware.net/。
  • 单击绿色的 DOWNLOAD 进入下载流程。

2.2 接受用户许可协议

  • 进入 MEGA User Agreement 页面。
  • 阅读后单击绿色的 Accept 继续。

2.3 填写基本信息并下载安装包

  • 按页面要求填写 Country（如 China）、机构与身份等信息。
  • 下载适用于本机的安装包（Windows 一般为 .exe）。

若国际网络较慢，可在遵守许可的前提下使用课程提供的离线安装包或单位镜像。

2.4 运行安装程序（Windows）

  • 双击 .exe；若出现 UAC 提示，确认来源可靠后允许。
  • 语言：首屏选择界面语言（多为 English），单击 OK。
  • 许可条款：勾选同意，单击 Next。
  • 安装路径：可用默认路径，或通过 Browse 指定后继续 Next。
  • 按向导提示依次 Next，直至完成文件复制。

2.5 完成安装并启动

  • 结束页单击 Finish；可按需勾选立即运行。
  • 也可从开始菜单或桌面快捷方式启动 MEGA 12。
  • 确认图形化主界面正常打开后，进入后续操作。

三、示例数据：Cyt b 蛋白序列

3.1 数据说明

本教程使用 20 个脊椎动物线粒体细胞色素 b（Cytochrome b，Cyt b）氨基酸序列 构建系统发育树。Cyt b 是线粒体基因组中常用的系统发育标记，适合课堂演示物种聚类关系。

  • 数据类型：蛋白质（amino acid），FASTA 格式
  • 文件：data/cytb_aa.fasta
  • 物种（20 条）：Human、Chimpanzee、Orangutan、Rhesus_macaque、Horse、Rabbit、Dog、Cat、Cattle、Sheep、Pig、Mouse、Rat、Guinea_pig、Chicken、Duck、Goose、African_clawed_frog、Zebrafish、Atlantic_salmon

建树时请确认导入类型为 Protein（不是 DNA/RNA）。

四、MEGA 12 构建分子进化树

整体流程：导入蛋白 FASTA → 多序列比对 → 保存对齐结果 → 选择建树方法 → Bootstrap → 导出树图。不同次要版本的菜单名称可能略有差异，以界面实际选项为准。

视频教程：MEGA 12 构建分子进化树（MP4）

4.1 导入蛋白序列

  • 启动 MEGA 12。
  • 在主界面选择 Align，打开 Alignment Explorer。
  • 通过 Edit / Data 菜单导入 cytb_aa.fasta。
  • 导入时选择数据类型为 Protein sequences（氨基酸），不要选 DNA/RNA。
  • 确认左侧出现 20 个物种名（Human、Chimpanzee、…、Atlantic_salmon）。

4.2 多序列比对

  • 在 Alignment Explorer 中选择 Align by MUSCLE（或 ClustalW）。
  • 确认比对对象为全部蛋白序列；参数可先用默认值。
  • 比对完成后，浏览对齐结果：两端是否整齐、是否有明显错位或大段异常 gap。
  • 将比对结果保存为 MEGA 工程文件（常用 .meg），例如 cytb_aa_aligned.meg。

4.3 修剪与质量检查

  • 若序列两端存在低一致性或不齐区域，可适度修剪，使多数物种覆盖同一比对区段。
  • 确认用于建树的是「已比对」数据，而不是原始未比对 FASTA。
  • 可用 Data → Export Alignment 另存一份比对后的 FASTA，便于留档。

4.4 选择建树方法与参数

  • 回到 MEGA 主界面，打开 Phylogeny，基于已对齐的蛋白数据建树。
  • 课堂推荐方法：
    • Neighbor-Joining（NJ）：速度快，适合首次跑通流程。
    • Maximum Likelihood（ML）：更常用于正式分析，计算时间更长。
    • Minimum Evolution（ME）：可作为方法比较的选做项。
  • 模型：数据类型为蛋白时，选择氨基酸替换模型（如 Jones-Taylor-Thornton (JTT)，或以软件推荐/课程要求为准）。不要误选核酸模型。
  • 缺口处理：对 gap/缺失位点常用 Complete Deletion 或 Partial Deletion（设置合理 site coverage）。
  • Bootstrap：勾选自助法；课堂演示可用 100，更稳定分析常用 500–1000。
  • 运行后打开 Tree Explorer 查看树形与节点支持率。

4.5 导出与展示

  • 在 Tree Explorer 中调整：分支长度显示、Bootstrap 数值位置、字体与标签。
  • 可尝试将鱼类（Zebrafish、Atlantic_salmon）或两栖类（African_clawed_frog）设为外群（outgroup）重新定根，便于观察脊椎动物各大类群的相对位置。
  • 导出：
    • Newick（.nwk）：供其他软件复用；
    • PNG / SVG：用于报告与课件。
  • 建议同时保存比对工程与树文件，便于比较 NJ / ML / ME 等不同方法的结果。

五、结果解读要点

完成建树后，可按下列线索检查结果是否合理（不同方法/参数下细节可能略有差异）：

  • 灵长类：Human、Chimpanzee、Orangutan、Rhesus_macaque 通常聚得较近；人与黑猩猩往往最近。
  • 偶蹄类：Cattle、Sheep、Pig 等常形成相关分支；Dog 与 Cat 等食肉类也可能相对靠近。
  • 啮齿类：Mouse、Rat 通常很近；Guinea_pig 常与之同属较大的啮齿相关类群。
  • 鸟类：Chicken、Duck、Goose 常聚为一支。
  • 外群趋势：鱼类、两栖类相对哺乳类/鸟类往往更靠外；若拓扑与预期差很大，优先复查是否误选了核酸模型、是否未完成比对。
